End to end

Three flows, step by step

A voice call becomes a lead

  1. A visitor starts a session. The server checks consent, gating and usage.
  2. The server mints a short-lived token. The browser never sees the real key.
  3. The browser streams audio to AssemblyAI and registers seven tools.
  4. The agent calls a tool, for example qualify_lead.
  5. The server applies guardrails and writes the lead to the CRM.
  6. The agent keeps talking. The conversation can seed a post draft.

Time to first audio is not measured yet, so there is no speed claim.

A draft becomes a post

  1. A signed-in seller submits text and picks an account.
  2. The server loads that workspace's own key and checks the account belongs to it.
  3. It creates a draft in TryPost. Every post starts as a draft.
  4. It asks TryPost to publish the draft.
  5. It reads the status back until TryPost says published.
  6. The receipt says published, or queued. It never says published early.

Proven end to end on Bluesky on 2026-09-26.

Buyer Lab, without the hype

  1. Page text is fetched or pasted, tagged public or signed-in.
  2. Simulated buyer personas read it.
  3. Every claim must carry a verbatim quote from what that persona saw. Others are dropped and counted.
  4. The report cites claim ids only.
  5. The output is hypotheses. No probability, conversion or revenue figure is produced.

One real-model check: 45 claims kept, 3 dropped.

Where it stops today

  • Speed is unmeasured. No latency figure is quoted until real calls are measured.
  • No calendar. The consultation tool records a request and a confirmation code. It does not book a slot.
  • Product questions use four documents. It is a keyword lookup, not document search.
  • One network auto-publishes. Bluesky only. X and LinkedIn need credentials, and other networks need their own app registration.
  • Billing is in test mode. No real money moves yet.
  • Sign-in uses shared development keys. Move to your own Google client before real customers sign in.
  • Widget calls are not metered. Only console calls count against a plan.
  • No duplicate protection on Publish. A double click can post twice.
